# 実装の判断

目標は公開情報の新作を、革と紙の本として選べる静的サイトにすること。

データは検証済みの Data と論理ページ配列で表す。現在の作品を示す focus と、見開きの左 index を分離する。resize 往復でも focus を保つ。見開きの通常移動では右の作品を focus にする。しおりは focus の作品 ID を保存する。

候補は DOM 全ページ常駐と現在のページのみ描画の2つ。後者を採用する。非表示リンクへのフォーカスや重複読み上げを避け、回転中だけ両面の紙を足す。

月は取得時点の日本時間の当月。stale は前回の期間を保持。予備の Wikidata は日本配信未確認と表紙・裏表紙で明示する。正常な0件と取得失敗を区別し、取得失敗は note に記録する。

めくり中 resize はめくり先で確定し待機入力を破棄。読み直し中の再操作を無効にし、成功は表紙に戻す。0件は全移動に優先する。しおりの不正 JSON、消失した作品は表紙。有効な作品 ID は古い index より優先する。

position の分母は裏表紙の index。非作品はページ種類を読み上げる。通信は画像差替えと明示的な Netflix リンク試行だけを例外とし実通信は遮断する。reduced-motion の上限は200ms。

公開物は .nojekyll を先に含めて検査後に push。実際の公開・実機ユニバーサルリンクは未実行として分けて報告する。

作業の区切りはルールとテスト、データ、UI、CI、実物検証。各区切りで実行結果を確認する。
